# 地理发现数据

本目录提供猹猹街 V1 的五城、行政区和 25 个公共地点服务锚点。坐标统一按 WGS84 解释，只用于服务端单次距离校验；客户端只能接收 `PublicSpotSummary` 和 `DistanceBand`，不得返回公共地点坐标与用户坐标的组合，也不得把用户位置写入存储或日志。

## 数据范围

- 城市：长沙、北京、上海、广州、深圳。
- 行政区：长沙 9 个县级行政区，北京 16 区，上海 16 区，广州 11 区，深圳 9 个行政区及大鹏新区。
- 公共地点：每城 5 个，共 25 个。地点选择公园、广场、博物馆等稳定、公开且适合步行到达的城市空间。
- 城市边界：`geography.ts` 当前使用各市公开经纬度范围整理出的简化服务包络，不是法定行政区界线或测绘成果。多边形边线视为城内；包络外返回“外来猹”。包络角落可能覆盖相邻地区，上线前应替换为经授权的行政区 GeoJSON，并保留当前边线包含语义。

## 行政区核验来源

- 北京：[北京市人民政府“走进北京”](https://www.beijing.gov.cn/renwen/index.html)（16 个市辖区）。
- 上海：[上海市民政局行政区划情况](https://www.shanghai.gov.cn/nw12344/20230105/6c75c59dad84431a8ad49a9c8f2ca8cb.html)（16 个区）。
- 广州：[广州市人民政府行政区域](https://www.gz.gov.cn/zlgz/gzgk/xzqy/)（11 个区）。
- 深圳：[深圳民政在线行政区划信息概况](https://mzj.sz.gov.cn/szmz/pc/bmxx/mzfwzy/xzqh/bmxx/content/post_2925240.html)（9 个行政区和大鹏新区）。
- 长沙：依据湖南省民政厅公开的县级以下行政区划代码表核对芙蓉、天心、岳麓、开福、雨花、望城 6 区，并列入长沙县、浏阳市、宁乡市；该清单需在上线前再次与长沙市民政局当期名录复核。

## 坐标核验方法

2026-08-04 使用 [OpenStreetMap Nominatim Search API](https://nominatim.org/release-docs/latest/api/Search/) 对地点名称和城市进行逐条、每秒不超过一次的查询，并检查返回地址中的城市和区。坐标保留为 WGS84；数据归属 © OpenStreetMap contributors，采用 [ODbL](https://www.openstreetmap.org/copyright)。湖南博物院另与 [Wikidata Q5942029](https://www.wikidata.org/wiki/Q5942029) 的坐标和开福区归属交叉核对。行政区归属同时按上述政府页面及地点官方地址复核。

代码中的 `verification` 含义：

- `verified`：自动查询得到 WGS84 坐标，且地点名称、城市、行政区一致。
- `prelaunch_review`：本轮自动查询无结果、存在地点范围歧义，或由 GCJ-02 公开坐标近似反算为 WGS84；只可用于本地功能联调，上线前必须现场 GPS 或合规地图服务复核并更新。

当前标记为“上线前复核”的锚点：海珠湖公园、白云山南门（云台花园）、深圳人才公园、宝安公园、龙城公园。尤其公园覆盖范围较大，500 米资格应锚定公开且可安全停留的明确入口，而不是整个园区中心。

## 隐私与精度约束

- Haversine、城市判断和 500 米资格函数均为无副作用纯函数，不缓存、不记录传入坐标。
- 埋瓜要求定位精度 `accuracyM <= 100`，并使用 `测得距离 + accuracyM <= 500` 的保守规则；缺失精度也视为低精度。
- 浏览发现允许缺失 `accuracyM`，但显式提供且大于 100 米时返回 `low_accuracy`，避免把明显不可信的位置归为本地。
- 行政区是发现排序标签，不是权限边界；排序仍按同区、同城、远方逐级回填。
