# 猹猹岛 V0 决策记录

## D-001 原创雷达岛

V0 使用 DOM、SVG 和 CSS 构建趣味雷达岛，不接入真实地图 SDK。理由是减少位置暴露、避免地图 Key 和坐标系依赖，并把视觉预算集中在吃瓜揭示与瓜田成长。

## D-002 城区不分池

行政区是排序标签，不是内容权限边界。发现顺序为同区、同城、远方，防止早期用户被分散到空池。

## D-003 单一资源

V0 只使用瓜籽。瓜籽通过有效吃瓜和自己的瓜被有效吃完获得，不消费。

## D-004 位置最小化

仅持久化公共地点坐标。用户精确坐标只在单次请求内完成距离判断，不写库、不进入业务日志。

## D-005 总控集成

功能任务使用独立 worktree 和分支。总控独占契约、根级配置和集成，功能任务通过消息提出接口或依赖变更。

## D-006 单任务故障隔离

总控不无限等待任何单个任务。各任务使用短提交保存检查点；卡死、崩溃或失联时从最后 commit 重建替代任务，其他工作流继续开发和集成。完整流程见 `RECOVERY.md`。

## D-007 晴日瓜田游乐场

界面采用单一明亮主题，视觉关键词是阳光、草地、海水、泥土和成熟西瓜。保留吃瓜、留籽、瓜田成长与底部导航的信息架构，退役夜色、书法、印章和日系静谧表达。主要动作统一使用西瓜珊瑚红，动态只用于发现、揭示、留籽和成长反馈，并提供减少动态模式。

## D-008 岛屿与地标是氛围层

每座开放城市是一座主岛，行政区和公共埋瓜点是岛上的地块。当前区域可显示代表性地标作为远景剪影或雷达锚点，但不构成真实地图，不表达用户精确位置，也不返回其他用户坐标。地标通过配置扩展，不写死在业务流程中。
