# 猹猹王国 V0 决策记录

## D-001 原创瓜域雷达

V0 使用 DOM、SVG 和 CSS 构建趣味瓜域雷达，不接入真实地图 SDK。理由是减少位置暴露、避免地图 Key 和坐标系依赖，并把视觉预算集中在吃瓜揭示与瓜田成长。

## D-002 城区不分池

行政区是排序标签，不是内容权限边界。发现顺序为同区、同城、远方，防止早期用户被分散到空池。

## D-003 单一资源

V0 只使用瓜籽。瓜籽通过有效吃瓜和自己的瓜被有效吃完获得，不消费。

## D-004 位置最小化

仅持久化公共地点坐标。用户精确坐标只在单次请求内完成距离判断，不写库、不进入业务日志。

## D-005 总控集成

功能任务使用独立 worktree 和分支。总控独占契约、根级配置和集成，功能任务通过消息提出接口或依赖变更。

## D-006 单任务故障隔离

总控不无限等待任何单个任务。各任务使用短提交保存检查点；卡死、崩溃或失联时从最后 commit 重建替代任务，其他工作流继续开发和集成。完整流程见 `RECOVERY.md`。

## D-007 晴日瓜田游乐场

界面采用同一套王国瓜域设计系统的昼夜两种环境状态。白天以阳光、草地、水域、泥土和成熟西瓜为主；夜晚切换为月光、树影和低饱和蓝绿，但不恢复书法、印章或日系静谧表达。主要动作统一使用西瓜珊瑚红，动态只用于发现、揭示、留籽和成长反馈，并提供减少动态模式。

## D-008 王国、城市瓜域与地标层级

“猹猹王国”是总世界观；每座开放城市是一个城市瓜域，行政区和公共埋瓜点是瓜域里的地块。岛屿、水岸与草坡只作为背景地貌保留，不再承担产品层级。当前区域可显示代表性地标作为远景剪影或雷达锚点，但不构成真实地图，不表达用户精确位置，也不返回其他用户坐标。地标通过配置扩展，不写死在业务流程中。

## D-009 手机端是主产品

375px 和 430px 手机视口是主要设计与验收基线，桌面端是增强布局。成熟瓜、主要操作和状态反馈优先落在单手拇指可达区域；弹层使用动态视口高度和安全区，输入框不能被底部导航遮挡。桌面适配不得反向增加移动端步骤或信息密度。

## D-010 偷感只属于吃瓜和埋瓜

城市瓜域与个人瓜田保持开放、轻快。打开瓜和埋瓜时进入短暂的原创潜瓜氛围，通过叶影收拢、草丛揭示和泥土合拢表达“偷偷发现”和“藏下一件事”。偷感不得削弱正文对比、触控命中或状态说明，也不得扩展成等级、任务、商城、排行或偷取他人资源。

## D-011 首屏只提供三种核心行动

成熟瓜的主动作是“吃瓜”，孵化中的土堆主动作是“旁观”，底部中央主动作是“埋瓜”。瓜田成长只反馈吃瓜和被吃的结果，不作为进入产品前的经营门槛。V0 不加入等级、任务、商城、皮肤、热榜、复杂心情或保鲜度配置。
